# Portfolio Website

A modern, responsive portfolio website showcasing my work as a Full Stack Developer.

## Features

- **Responsive Design**: Works on all devices
- **Modern UI**: Clean and professional design
- **Tech Stack Display**: Interactive skills showcase
- **Project Portfolio**: Detailed project presentations
- **Contact Form**: Direct communication

## Technologies Used

- HTML5, CSS3, JavaScript
- CSS Grid & Flexbox
- Anime.js for animations
- Responsive design principles

## Quick Start

1. Clone or download this repository
2. Open `index.html` in your browser
3. Customize content in `index.html`
4. Update styles in `css/styles.css`
5. Replace images in `images/` folder

## File Structure

```
├── index.html          # Main portfolio page
├── css/
│   ├── styles.css      # Custom styles
│   └── vendor.css      # Third-party styles
├── js/
│   ├── main.js         # Custom JavaScript
│   └── plugins.js      # Third-party plugins
├── images/
│   ├── about-photo.jpg # Profile image
│   ├── icons/          # SVG icons
│   └── portfolio/      # Project images
├── favicon.jpg         # Website favicon
└── site.webmanifest   # Web app manifest
```

## Customization

1. **Personal Information**: Update name, email, and bio in `index.html`
2. **Profile Image**: Replace `images/about-photo.jpg` and `about-photo@2x.jpg`
3. **Projects**: Update project details and images in the portfolio section
4. **Tech Stack**: Modify the skills grid in the tech stack section
5. **Colors**: Customize CSS variables in `css/styles.css`
